How Flood Fill Works

Flood Fill starts from a selected cell and explores connected neighboring cells.

This project visualizes the process using a BFS-style queue.

Each cell is represented as a matrix coordinate:
[row, column]

The algorithm checks the eight surrounding positions, avoids already visited cells, and expands through safe regions.
